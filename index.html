Anchored Pathways Evidence Dashboard

Current 2025–2026 data on Texas college access, persistence, transfer, and workforce outcomes. Each point includes a plain-language explanation and a source link so users can check the original evidence.

How to use this dashboard: Select one or more data points in the chart, or use the filters to narrow the view. The Why AP Is Needed section helps you turn selected data into a short plain-language summary of the need. It highlights the most important points so funders, partners, and families can quickly understand the current evidence.
Tip: hold Ctrl/Command to select more than one item in the filters.
